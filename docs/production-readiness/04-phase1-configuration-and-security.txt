PARTIALLY VERIFIED: locations confirmed, credential validity NOT VERIFIED.
/home/runner/work/exam-cursor/exam-cursor/Backend-API/appsettings.json:4,8,11,19,54,214
The specialist identified connection/security/provider-related settings at

Required: inventory consumers, replace tracked deployment values with safe
templates, use deployment-secret/environment providers or protected settings,

2. SQL server certificate validation is disabled in the checked-in connection.
VERIFIED source behavior, MEDIUM severity, specialist confidence 9/10.
/home/runner/work/exam-cursor/exam-cursor/Backend-API/appsettings.json:4
/home/runner/work/exam-cursor/exam-cursor/Backend-API/Program.cs:72-73

5. Frontend configuration must distinguish API base from backend origin.
VERIFIED in source:
/home/runner/work/exam-cursor/exam-cursor/Frontend/Smart-Exam-App-main/app/api/proxy/[...path]/route.ts:3-14
/home/runner/work/exam-cursor/exam-cursor/Frontend/Smart-Exam-App-main/next.config.mjs:10-23
/home/runner/work/exam-cursor/exam-cursor/Frontend/Smart-Exam-App-main/lib/signalr/notification-hub.ts:65-72
The server proxy appends endpoint paths to BACKEND_URL (or
NEXT_PUBLIC_BACKEND_URL), with a default including /api. Media rewrites strip
/api; browser SignalR strips it and uses the origin. A single mistaken value can
leave REST working but break real-time/media, or vice versa.

Required template/documentation coverage after remediation:
- Backend SQL connection, JWT issuer/audience/key and encryption configuration.
- Allowed browser origins, trusted load-balancer forwarding, storage locations,
  license distribution, SMTP/SMS and notification login URL settings.
- Server-only BACKEND_URL pointing to the API base (including /api in the current
  implementation), and browser-visible NEXT_PUBLIC_BACKEND_URL for the reachable
  backend. NEXT_PUBLIC_* values are public and normally baked into Next.js builds;
  they must never contain credentials.
- Redis/backplane settings only if actually supported by the final implementation.
- WebRTC ICE/TURN and AI/model/CDN dependencies, offline reachability, log
  retention, service identities, least-privilege permissions, and backup/restore.
No customer-ready template was invented before these contracts were validated.

6. Existing deployment instructions cannot be used unchanged.
VERIFIED discrepancies:
/home/runner/work/exam-cursor/exam-cursor/docs/ONPREMISE_DEPLOYMENT_GUIDE.md:22-32,193-197,222-223
The guide suggests .NET 8 while the API targets net9.0. It shows

exceptions when real example files are added; never unignore real credentials.
